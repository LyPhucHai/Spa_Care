# Thực hiện dịch vụ — Java

Demo độc lập. Cần **JDK 17+ và Maven**.

**Windows:** `run.bat`.

**macOS / Linux:** `sh run.sh`.

Chạy lệnh tại thư mục `Java`. Main class: [`ServiceDemo`](src/main/java/spacare/ServiceDemo.java). H2 tạo dữ liệu mới trong RAM mỗi lần chạy.

Xem [kịch bản](../GUIDE.md) và [UI](../UI/index.html). `[BỊ TỪ CHỐI]` là kết quả dự kiến của thao tác sai.
