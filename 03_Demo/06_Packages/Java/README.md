# 06_Packages - Java

Một chương trình console gộp: đặt lịch (lẻ, combo, dùng buổi liệu trình, đôi/nhóm), thanh toán, tích điểm, nâng hạng, bán gói liệu trình.

- Yêu cầu: JDK 17 trở lên. Maven là tùy chọn (dùng `run_nomaven.bat` nếu chưa có).
- Dữ liệu mặc định nằm trong RAM; chạy với `saved` để lưu ra file `data\spacare`.
- Các lệnh chạy, kịch bản và kết quả mong đợi: xem `../GUIDE.md`.
- `Pricing.java` chứa toàn bộ luật tính giá, `PricingCheck.java` kiểm tra luật này mà không cần CSDL.
